# Лига Ultimate Royale — фронт

Сайт лиги Ultimate Royale по PUBG Mobile: главная с текущим матчем, рейтинг, профили игроков,
кабинет организатора и оверлей для OBS. Next.js 16 (App Router, TypeScript, Turbopack)
+ React 19 + Tailwind v4.

Проект начат 19.10.2026 как копия фронта GOARC (сайт лиги по ARC Raiders): что меняется и в каком
порядке — в README в корне `UR_League`.

> **Сайт состоит из двух проектов в разных репозиториях:**
> - **frontend** — этот репозиторий: страницы сайта;
> - **backend** — соседняя папка `backend`: сервер на Go и база данных, откуда сайт берёт все данные.
>
> Сначала запустите бэкенд по инструкции из его README — там же установка программ и база данных.
> Потом — этот фронтенд по шагам ниже. Без бэкенда страницы откроются пустыми.

## Как запустить у себя (пошагово)

Команды вводятся в терминале. На Windows используйте **Git Bash** — он ставится вместе с Git:
правый клик по папке → «Open Git Bash here».

### 1. Запустите бэкенд

Пройдите шаги 1–6 из README бэкенда (папка `backend` рядом с этой). Там установка программ
(включая Node.js), скачивание обоих проектов в одну папку, база данных и сервер.

Проверка, что бэкенд работает: http://localhost:8090/api/health показывает `{"ok":true,...}`.

### 2. Установите зависимости

```bash
cd frontend
npm ci
```

Займёт пару минут: npm скачает библиотеки в папку `node_modules`. Повторять нужно только когда
в проекте поменялся `package.json`.

### 3. Укажите, где работает бэкенд

Создайте в папке `frontend` файл `.env.local` с двумя строками:

```ini
BACKEND_ORIGIN=http://127.0.0.1:8090
INTERNAL_API_URL=http://127.0.0.1:8090
```

То же самое одной командой:

```bash
printf 'BACKEND_ORIGIN=http://127.0.0.1:8090\nINTERNAL_API_URL=http://127.0.0.1:8090\n' > .env.local
```

- `BACKEND_ORIGIN` — куда сайт пересылает запросы браузера к `/api`.
- `INTERNAL_API_URL` — куда страницы обращаются за данными при отрисовке на сервере.

Если бэкенд запущен на другом порту (например, вы указали в его `.env` строку `PORT=8091`), впишите
здесь этот порт в обе строки. Файл `.env.local` в git не попадает.

### 4. Запустите сайт

```bash
npm run dev
```

Когда в терминале появится `Ready`, откройте:

- http://localhost:3110 — сайт;
- http://localhost:3110/admin — кабинет организатора: войдите под логином `Istwood` с паролем
  из строки `SUPERADMIN_PASSWORD` в `.env` бэкенда;
- http://localhost:3110/overlay — оверлей для OBS.

Терминал не закрывайте: пока он открыт, сайт работает. Остановить — `Ctrl+C`. Правки в коде
появляются в браузере сразу, перезапускать не нужно.

### Если что-то не работает

- **Страницы пустые или пишут «Что-то пошло не так»** — не запущен бэкенд или в `.env.local`
  неверный порт. Проверьте http://localhost:8090/api/health (или ваш порт) и перезапустите
  `npm run dev` после правки `.env.local`.
- **`npm ci` ругается на версию** — нужна Node.js 20 или новее: `node -v`.
- **Не применяются правки стилей в `globals.css`** — остановите сайт, удалите папку `.next/dev`
  и снова запустите `npm run dev`.
- **Порт 3110 занят** — запустите на другом: `npx next dev -p 3200`, и в `.env` бэкенда поменяйте
  `FRONTEND_URL` на `http://localhost:3200`.
- **Не получается войти в кабинет** — пароль организатора задаётся в `.env` бэкенда и применяется
  при его запуске: поправьте `SUPERADMIN_PASSWORD` и перезапустите бэкенд.

### Для разработчика

Перед коммитом — те же проверки, что делает CI перед выкладкой:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Возможности

Что ещё переделывается под Ultimate Royale и в каком порядке — README в корне `UR_League`.

**Сайт (дизайн «Высадка»):**
- Главная: идущий матч со счётом и заходами раундов, анонс шоу-матча, пояс лиги, топ сезона.
- Рейтинг по сезонам (1×1 и команды 2×2), архив сыгранных матчей, расписание шоу-матчей.
- Страница матча: раунды с заходами сторон (карта, киллы, место), задания, изменение MMR.
- Профиль игрока: игровой ID и ник, теги, график MMR по сезонам, места в заходах, история матчей.
- Правила и справочник заданий, нашивки, лучшие моменты, заявка на участие.

**Кабинет организатора (`/admin`):**
- Матчи: новый матч 1×1 одной формой (×2 по желанию) или шоу-матч на дату; пульт матча —
  заходы по очереди, карта и место захода, киллы, зачёт заданий, ручные очки, легендарки,
  журнал с отменой.
- Оверлей: сцены для OBS и раскладка виджетов, превью на кадрах PUBG Mobile.
- Задания и протоколы, легендарки, сезоны (K и стартовый MMR), игроки, теги, заявки, хайлайты.

**OBS-оверлей (`/overlay`):** табло, задания, киллы захода, кто в кадре и другие виджеты;
обновляется сам по WebSocket.

## Структура

- `src/app/(site)` — публичные страницы; `src/app/admin` — кабинет; `src/app/overlay` — оверлей.
- `src/components/` — `ui/` (база: Button/Pill/Panel…), `domain/`, `admin/`, `overlay/`;
  `surface/` — страницы сайта (стили в `src/app/surface.css`, классы с префиксом `sf-`).
- `src/lib/` — `api.ts`/`server-api.ts` (клиент к `/api`), `queries.ts`, `types.ts`
  (зеркало Go-моделей), `ws.ts`, `format.ts`, `display.ts`, `auth.tsx`.

## Выкладка на прод

Сайт лиги открыт на `zolotoyarena.pro`: nginx отдаёт страницы этого фронта (:3010), а `/api`
передаёт Go API (:8090). Выкладка автоматическая: push в `main` — GitHub Actions проверяет код,
собирает сайт и выкладывает его на сервер (`.github/workflows/deploy.yml`). `NEXT_PUBLIC_API_BASE`
вшивается при сборке из `.env.production`. Настройка сервера — `deploy/DEPLOY.md` в корне `UR_League`.
